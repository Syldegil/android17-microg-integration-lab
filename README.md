# android17-microg-integration-lab

Android17 microG integration research: restricted query-time signature policy, PackageManager tests, App Links policy, offline RKP and CT distribution adaptations. Reproducible host fixtures are included; no firmware or installable Phone ROM.

Experimental sources maintained by Syldegil. [Français](README.fr.md).
